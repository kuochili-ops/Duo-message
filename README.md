# 𓃥 白六 Duo 訊息編輯 (Duo Message Editor)

一個專為 iOS / WebViews 優化的 3D 摺疊雙頁訊息傳遞與動態錄影工具。模擬雙螢幕/雙頁摺疊（Duo）的動態展頁效果，搭配精緻的毛玻璃質感與客製化文字排版，輕鬆製作並導出高品質的訊息短片。

🔗 **線上預覽體驗**：[https://kuochili-ops.github.io/Duo-message/](https://kuochili-ops.github.io/Duo-message/)

---

## ✨ 核心特色

- **📱 擬真 3D 雙頁展開**：支援手指與滑鼠直覺拖曳翻頁，擬真 3D 軸心旋轉、光影掠過與中脊陰影。
- **✨ 高品質毛玻璃質感 (Glassmorphism)**：兼具動態模糊透出與極佳視效，並透過預模糊技術優化錄影表現。
- **🔤 Google 中文字型支援**：內建思源黑體、思源宋體、馬善政毛筆楷體及酷樂圓體，文字尺寸與顏色皆可自由調節。
- **📋 多元圖片載入方式**：支援本地檔案上傳、讀取剪貼簿圖片按鈕以及鍵盤 `Ctrl+V` 直接貼上。
- **🎥 雙模式影片導出**：
  - **自動錄影**：一鍵按照設定的翻頁速度自動播放並生成 WebM 影片。
  - **手動觸控錄影**：自由記錄手指親自滑動翻頁的真實軌跡與節奏。
- **⚡ 針對 iOS / Koder 瀏覽器深度優化**：
  - **防全頁滾動**：滑動手勢精準鎖定於手機元件，解決觸控時網頁上下橡皮筋拉伸問題。
  - **圖片動態降採樣 (Downsampling)**：自動優化大圖解析度與記憶體佔用，防範 WebView 記憶體溢出閃退。
  - **Aspect Fill 原圖保護**：圖像自動保持原始縱橫比（Aspect Ratio）置中裁切，絕不拉伸變形。

## 🚀 使用說明

1. **圖片設定**：點擊選取圖片、使用「📋 讀取剪貼簿圖片」按鈕或直接以 `Ctrl+V` 貼上欲展示的背景照片。
2. **訊息編輯**：輸入預計傳遞的文字，並設定偏好的 Google 中文字型、顏色與字型大小。
3. **預覽與操控**：點擊「預覽動畫」切換至預覽面板：
   - 使用「開 / 闔切換」按鈕快速檢視展開與折疊狀態。
   - 在手機螢幕上左右滑動手指體驗手動翻頁。
   - 調整「翻頁速度」滑桿改變自動展開的動畫時間。
4. **影片錄製**：點擊「自動錄影」或「手動觸控錄影」，完成後瀏覽器將自動下載 `.webm` 格式影片。

## 🛠️ 技術架構

- **前端技術**：HTML5, CSS3 (3D Transforms, Backdrop Filter, Flexbox), Vanilla JavaScript (ES6+)
- **字型庫**：Google Fonts API
- **圖像處理與動畫**：Canvas API, `requestAnimationFrame`, Aspect Fill 繪製演算
- **媒體錄製**：MediaRecorder API (`canvas.captureStream`)
